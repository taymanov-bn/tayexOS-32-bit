
# tayexOS (32-bit RISC-V)

Учебное 32-битное ядро операционной системы для архитектуры RISC-V, написанное с нуля на языке C без использования стандартной библиотеки (`-nostdlib`).

## Цель проекта

Этот проект служит тренировочным перед разработкой основного 64-битного ядра (`RV64`). Более компактный 32-битный формат позволяет без лишнего шума разобраться во внутреннем устройстве операционной системы: от начальной загрузки на «голом» железе и работы с OpenSBI до обработки прерываний, страничной памяти и переключения контекста процессов.

## Стек и инструменты

* **Архитектура:** RISC-V (`RV32`)
* **Языки:** C (C11), RISC-V Assembly
* **Сборка:** `clang`, линкер `lld` (`-ffreestanding -nostdlib`)
* **Эмуляция:** `qemu-system-riscv32` + прошивка OpenSBI
